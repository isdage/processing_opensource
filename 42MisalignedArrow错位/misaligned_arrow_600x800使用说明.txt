========================================
1. 基本信息
========================================

程序名称：misaligned_arrow_600x800 错位反向箭头
开发环境：Processing 3.x 或 4.x
画布尺寸：600 x 800 像素

主要特点：
  - 鼠标按住拖动时，会出现一支半透明轨迹箭头
  - 鼠标松开后，会在拖动开始的位置生成一支反向箭头
  - 反向箭头会被限制在方框内部漂浮和反弹
  - 箭头撞到方框边缘时，方框会短暂闪动
  - 当两支箭头的箭头尖正面对上时，会触发掉落
  - 掉落后的箭头会离开方框，落到画面底部停住
  - 按 R 键可以清空画面并重置状态
  - 支持使用背景图片，也可以切换回纯色背景

创作含义：
  - 鼠标的动作方向和生成箭头方向相反，表达“错位”
  - 方框像一个关系场或边界
  - 箭头在框内来回反弹，表现持续的对抗和偏移
  - 只有箭头尖正面对上时才掉落，表现“争锋相对”的瞬间


========================================
2. 安装与运行
========================================

步骤1：安装 Processing
  - 访问 https://processing.org/download
  - 下载并安装适合你电脑系统的版本

步骤2：打开项目文件夹
  - 找到项目文件夹：misaligned_arrow_600x800
  - 打开 misaligned_arrow_600x800.pde

步骤3：确认资源文件
  - 背景图片 background.jpg 需要放在项目文件夹里
  - 当前路径应为：misaligned_arrow_600x800/background.jpg
  - 当前程序不需要安装额外库
  - 当前程序不使用声音、麦克风或摄像头

步骤4：运行程序
  - 点击 Processing 左上角的运行按钮
  - 或按快捷键：
    Windows/Linux：Ctrl + R
    Mac：Cmd + R

注意：
  - Processing 项目文件夹名称需要和主 pde 文件名称一致
  - 如果背景图片没有显示，确认 background.jpg 是否在项目文件夹中
  - 如果换了背景图片文件名，需要同步修改代码里的 backgroundImageName


========================================
3. 交互方式
========================================

鼠标拖动：
  - 按住鼠标并拖动
  - 拖动时会显示一支半透明箭头
  - 这支箭头表示你鼠标当前拖动的方向
  - 鼠标拖动距离太短时，不会生成新的反向箭头

松开鼠标：
  - 松开鼠标后，会生成一支新的小箭头
  - 小箭头出现的位置是鼠标开始拖动的位置
  - 小箭头的方向和鼠标拖动方向相反
  - 例如向左拖动，会生成向右的小箭头
  - 例如向右拖动，会生成向左的小箭头

方框内漂浮反弹：
  - 生成后的小箭头会在方框内部移动
  - 小箭头碰到方框边缘时会反弹
  - 每次碰到方框边缘，方框会闪动一下

箭头争锋相对掉落：
  - 箭头之间不会普通碰撞就掉落
  - 只有当两支箭头的箭头尖非常接近，并且方向接近相反时，才会触发掉落
  - 掉落后，箭头不再受方框限制
  - 掉落的箭头会向画面底部落下，并停在设定高度

R 键：重置画面
  - 按 R 键清空所有箭头
  - 取消正在拖动的轨迹提示
  - 停止方框闪动
  - 画面回到初始状态


========================================
4. 画面结构说明
========================================

画面由这些部分组成：
  - 背景图片 background.jpg，或纯色背景 backgroundColor
  - 一个固定方框
  - 鼠标拖动时出现的轨迹箭头
  - 方框内漂浮反弹的小箭头
  - 碰撞后掉落到底部的小箭头

图层顺序：
  1. 背景图片或背景色
  2. 所有箭头的位置更新和碰撞检测
  3. 方框
  4. 鼠标拖动轨迹箭头
  5. 漂浮或掉落的小箭头

说明：
  - 所有小箭头都是 FloatingArrow 对象
  - 每个小箭头有自己的位置、方向、速度、生命时间和掉落状态
  - 正常状态下，小箭头只在方框内部反弹
  - falling 表示箭头正在掉落
  - landed 表示箭头已经落到底部并停住
  - 方框闪动由 boxFlashTimer 控制
  - 背景图片通过 backgroundImageName 加载


========================================
5. 参数调整指南
========================================

提示：
  - 使用 Ctrl + F 或 Cmd + F 搜索参数名称
  - 修改数值后重新运行程序查看效果
  - 建议每次只改一两个参数，方便判断变化
  - 主要参数集中在代码顶部“你主要改这里”的区域

----------------------------------------
画布和背景
----------------------------------------

【画布尺寸】
代码：size(600, 800);
说明：
  - 600 是画布宽度
  - 800 是画布高度
  - 如果修改画布尺寸，方框距离、落地高度等参数也可能需要一起调整

【纯色背景】
代码：color backgroundColor = #eeeeee;
说明：
  - 当 useBackgroundImage 为 false 时，会显示这个背景颜色
  - 当前颜色是浅灰色 #eeeeee

【背景图片文件名】
代码：String backgroundImageName = "background.jpg";
说明：
  - 控制程序加载哪张背景图片
  - 图片需要放在项目文件夹里
  - 文件名需要和这里完全一致

【是否使用背景图片】
代码：boolean useBackgroundImage = true;
说明：
  - true 表示使用 background.jpg
  - false 表示使用 backgroundColor 纯色背景
  - 如果想临时不用图片，可以改成 false

----------------------------------------
方框参数
----------------------------------------

【方框位置】
代码：
  float boxLeftGap = 100;
  float boxRightGap = 100;
  float boxTopGap = 80;
  float boxBottomGap = 220;
说明：
  - boxLeftGap 控制方框左边离画面左边的距离
  - boxRightGap 控制方框右边离画面右边的距离
  - boxTopGap 控制方框上边离画面上边的距离
  - boxBottomGap 控制方框下边离画面下边的距离
  - 单位都是像素

【方框透明度】
代码：float boxAlpha = 100;
说明：
  - 控制方框正常状态下的透明度
  - 范围建议为 0 到 255
  - 数字越大，方框越明显

【方框线条粗细】
代码：float boxWeight = 1.5;
说明：
  - 数字越大，方框线条越粗
  - 数字越小，方框线条越细

【方框闪动】
代码：
  float boxFlashAlpha = 150;
  float boxFlashWeight = 3;
  int boxFlashFrames = 5;
说明：
  - 箭头撞到方框边缘时，方框会闪动
  - boxFlashAlpha 控制闪动时透明度
  - boxFlashWeight 控制闪动时线条粗细
  - boxFlashFrames 控制闪动持续时间

【方框发光】
代码：
  float boxGlowAlpha = 0;
  float boxGlowWeight = 0;
说明：
  - 当前发光已经关闭
  - 如果想开启微微发光，可以把 boxGlowAlpha 改大，例如 15 到 30
  - 如果想让光晕更散，可以把 boxGlowWeight 改大，例如 5 到 10

----------------------------------------
鼠标拖动轨迹箭头
----------------------------------------

【拖动触发距离】
代码：float minSwipe = 18;
说明：
  - 鼠标拖动超过这个距离才会生成反向箭头
  - 数字越小，越容易生成箭头
  - 数字越大，需要拖得更远才会生成

【轨迹箭头透明度】
代码：float dragHintAlpha = 120;
说明：
  - 控制鼠标拖动时临时箭头的透明度
  - 数字越大越明显

【轨迹箭头粗细】
代码：float dragHintWeight = 1.4;
说明：
  - 控制鼠标拖动时临时箭头的线条粗细

----------------------------------------
漂浮小箭头
----------------------------------------

【箭头颜色】
代码：color arrowColor = #777777;
说明：
  - 控制轨迹箭头和漂浮小箭头的颜色
  - 当前是灰色 #777777

【箭头大小】
代码：
  float floatingArrowBody = 28;
  float floatingArrowHead = 9;
说明：
  - floatingArrowBody 控制箭头身体长度
  - floatingArrowHead 控制箭头头部大小
  - 数字越大，箭头越大

【箭头线条粗细】
代码：float floatingArrowWeight = 2;
说明：
  - 控制漂浮小箭头的线条粗细
  - 数字越大，箭头越粗

【箭头移动速度】
代码：float floatingArrowSpeed = 1.1;
说明：
  - 控制小箭头在方框内移动的速度
  - 数字越大，移动越快
  - 数字越小，移动越慢

【箭头晃动幅度】
代码：float floatingArrowWobble = 0.35;
说明：
  - 控制小箭头漂浮时的轻微晃动
  - 0 表示完全直线运动
  - 数字越大，晃动越明显

【箭头出现时间】
代码：float floatingArrowAppearFrames = 12;
说明：
  - 控制新箭头从淡到清晰的时间
  - 数字越大，出现越慢
  - 数字越小，出现越快

【箭头发光】
代码：
  float arrowGlowAlpha = 0;
  float arrowGlowWeight = 0;
说明：
  - 当前发光已经关闭
  - 如果想开启微微发光，可以把 arrowGlowAlpha 改大，例如 20 到 40
  - 如果想让光晕更散，可以把 arrowGlowWeight 改大，例如 5 到 10

----------------------------------------
争锋相对和掉落
----------------------------------------

【箭头尖距离】
代码：float arrowTipDistance = 5;
说明：
  - 控制两支箭头的箭头尖多近时才可能触发掉落
  - 数字越大，越容易触发
  - 数字越小，越需要箭头尖非常接近

【方向相反程度】
代码：float arrowOppositeAmount = 0.75;
说明：
  - 控制两支箭头方向需要多相反
  - 越接近 1，越需要正面对上
  - 数字越小，判断会更宽松

【掉落重力】
代码：float arrowFallGravity = 0.18;
说明：
  - 控制箭头掉落时速度增长
  - 数字越大，掉得越快
  - 数字越小，掉得越慢

【落地位置】
代码：float arrowFloorY = 760;
说明：
  - 控制箭头最后停在画面中的高度
  - 数字越大，落点越靠下
  - 数字越小，落点越靠上

快捷键

========================================
6. 常见问题
========================================

问题1：背景图片没有显示
  - 确认 background.jpg 放在 misaligned_arrow_600x800 文件夹里
  - 确认代码里的 backgroundImageName 和文件名完全一致
  - 确认 useBackgroundImage 是 true
  - 如果仍然没有显示，可以先把 useBackgroundImage 改成 false 使用纯色背景

问题2：背景图片被拉伸
  - 当前程序会把图片直接铺满 600 x 800 画布
  - 如果图片比例和画布比例不同，会有轻微拉伸
  - 可以把背景图裁成 600 x 800 再替换

问题3：鼠标拖动没有生成小箭头
  - 确认是按住鼠标拖动后松开
  - 确认拖动距离超过 minSwipe
  - 如果想更容易生成，把 minSwipe 改小

问题4：箭头生成位置不在鼠标松开位置
  - 这是当前设计
  - 箭头会从鼠标开始拖动的位置出现
  - 方向则和鼠标拖动方向相反

问题5：箭头为什么只在方框里动
  - 这是当前设计
  - 正常漂浮状态下，小箭头会被限制在方框内部反弹
  - 只有触发“争锋相对”掉落后，才会离开方框

问题6：箭头太容易掉落
  - 减小 arrowTipDistance
  - 增大 arrowOppositeAmount
  - 也可以减小 floatingArrowSpeed，让箭头更慢更难正面对上

问题7：箭头很难掉落
  - 增大 arrowTipDistance
  - 减小 arrowOppositeAmount
  - 增大 floatingArrowSpeed，让箭头更容易靠近

问题8：方框闪动太明显
  - 减小 boxFlashAlpha
  - 减小 boxFlashWeight
  - 减小 boxFlashFrames

问题9：方框闪动太弱
  - 增大 boxFlashAlpha
  - 增大 boxFlashWeight
  - 增大 boxFlashFrames

问题10：箭头颜色不清楚
  - 修改 arrowColor
  - 例如 #000000 是黑色
  - 例如 #777777 是灰色
  - 例如 #ffffff 是白色

问题11：想重新开始画面
  - 按 R 键
  - R 键会清空所有箭头，并停止边框闪动

问题12：运行有卡顿
  - 按 R 清空画面
  - 减少生成箭头数量
  - 减小 smooth(8) 的数值，例如改成 smooth(4)
  - 减小发光参数 boxGlowWeight 和 arrowGlowWeight，当前版本默认已经关闭发光
