========================================
1. 基本信息
========================================

程序名称：dense_stacked_characters_600x800 消融文字气泡
开发环境：Processing 3.x 或 4.x
画布尺寸：600 x 800 像素

主要特点：
  - 画面左侧生成多行被压缩堆叠的英文字符
  - 每行文字内容不同，但都从左侧密集开始
  - 字符越靠左间距越窄，越往右逐渐疏离
  - 鼠标移动到某一行附近时，这一行会被触发
  - 被触发的一行会从右到左逐字散开
  - 散开的字符像气泡一样向右上方漂浮
  - 字符不会消失，会一直在设定方框范围内浮动和反弹
  - 鼠标经过漂浮字符附近时，会产生搅动效果
  - 按 R 键可以重置画面
  - 支持背景图片，也可以在图片缺失时显示纯色背景

创作含义：
  - 初始压缩的文字像被折叠、堆积、尚未展开的语言
  - 鼠标触碰某一行后，文字像泡腾片一样被激活
  - 从右到左的散开过程表现语言逐步消融
  - 方框是一个看不见但真实存在的边界
  - 漂浮字符在边界中反弹和被搅动，像无法完全离开的残余话语


========================================
2. 安装与运行
========================================

步骤1：安装 Processing
  - 访问 https://processing.org/download
  - 下载并安装适合你电脑系统的版本

步骤2：打开项目文件夹
  - 找到项目文件夹：dense_stacked_characters_600x800
  - 打开 dense_stacked_characters_600x800.pde

步骤3：确认资源文件
  - 背景图片需要放在项目文件夹里
  - 当前代码中的背景图片文件名是：backgroud.jpg
  - 当前路径应为：dense_stacked_characters_600x800/backgroud.jpg
  - 当前程序不需要安装额外库
  - 当前程序不使用声音、麦克风或摄像头

步骤4：运行程序
  - 点击 Processing 左上角的运行按钮
  - 或按快捷键：
    Windows/Linux：Ctrl + R
    Mac：Cmd + R

注意：
  - Processing 项目文件夹名称需要和主 pde 文件名称一致
  - 如果背景图片没有显示，确认 backgroud.jpg 是否在项目文件夹中
  - 如果换了背景图片文件名，需要同步修改代码里的 backgroundFile
  - 当前背景文件名是 backgroud.jpg，如果改成 background.jpg，代码里也要一起改


========================================
3. 交互方式
========================================

初始画面：
  - 打开程序后，画面左侧会出现多行英文字符
  - 每行字符都被压缩在左侧
  - 越靠左的字符间距越窄，越往右逐渐变疏
  - 初始字符不旋转，保持正向

鼠标触发行：
  - 鼠标移动到某一行的范围内时，会触发这一整行
  - 触发范围由 touchYRange 控制
  - 一行只会被触发一次
  - 被触发后，这一行会从最右侧字符开始，逐字向左推进散开

字符气泡浮动：
  - 触发后的字符会向右上方飘动
  - 字符不会淡出消失
  - 字符会留在隐藏方框范围内持续浮动
  - 碰到方框边缘会反弹

鼠标搅动：
  - 当字符已经漂浮后，鼠标经过它们附近会产生搅动
  - 字符会被鼠标推开，并带一点旋涡式运动
  - 鼠标移动越快，搅动越明显
  - 旋转和速度会有阻尼，不会无限加速

R 键：重置画面
  - 按 R 键重新生成所有文字
  - 所有已经漂浮的字符回到初始堆叠状态
  - 所有已触发的行恢复为未触发


========================================
4. 画面结构说明
========================================

画面由这些部分组成：
  - 背景图片 backgroud.jpg，或纯色背景 backgroundGray
  - 左侧压缩堆叠的英文字符
  - 一个隐藏的漂浮范围方框
  - 被触发后在方框中持续漂浮的字符
  - 鼠标经过漂浮字符时产生的搅动效果

图层顺序：
  1. 背景图片或背景色
  2. 隐藏方框，如果 showBox 为 true 则显示
  3. 尚未触发的静止文字缓存层
  4. 已触发并正在漂浮的字符

说明：
  - 所有字符都是 Glyph 对象
  - rowGlyphs 保存每一行包含哪些字符
  - rowStarted 记录每一行是否已经触发
  - floating 表示字符已经从静止文字层进入漂浮状态
  - evaporating 表示字符已经开始运动
  - waitFrames 控制一行中每个字符依次散开的时间差
  - staticTextLayer 用来缓存未触发的静止文字，减少卡顿
  - glyphImage 是每个字符预先渲染好的小图，也用于提升性能

5. 参数调整指南
========================================

提示：
  - 使用 Ctrl + F 或 Cmd + F 搜索参数名称
  - 修改数值后重新运行程序查看效果
  - 建议每次只改一两个参数，方便判断变化
  - 主要参数集中在代码顶部“可调参数”区域

----------------------------------------
画布和背景
----------------------------------------

【画布尺寸】
代码：size(600, 800);
说明：
  - 600 是画布宽度
  - 800 是画布高度
  - 如果修改画布尺寸，方框和文字位置也可能需要一起调整

【纯色背景】
代码：
  int backgroundGray = 246;
说明：
  - 当背景图片加载失败时，会显示这个灰度背景
  - 0 是黑色，255 是白色

【背景图片文件名】
代码：
  String backgroundFile = "backgroud.jpg";
说明：
  - 控制程序加载哪张背景图片
  - 图片需要放在项目文件夹里
  - 文件名需要和这里完全一致

----------------------------------------
漂浮范围方框
----------------------------------------

【是否显示方框】
代码：
  boolean showBox = false;
说明：
  - false 表示隐藏方框，但范围依旧生效
  - true 表示显示方框，方便调位置和大小

【方框位置与大小】
代码：
  float boxX = 55;
  float boxY = 105;
  float boxW = 480;
  float boxH = 630;
说明：
  - boxX 控制方框左上角 x 坐标
  - boxY 控制方框左上角 y 坐标
  - boxW 控制方框宽度
  - boxH 控制方框高度
  - 字符漂浮和反弹都会被限制在这个范围内

【方框透明度】
代码：
  float boxAlpha = 120;
说明：
  - 只有 showBox 为 true 时才看得到
  - 数字越大，方框越明显
  - 数字越小，方框越淡

【方框线条粗细】
代码：
  float boxStrokeWeight = 1.5;
说明：
  - 数字越大，方框线条越粗
  - 数字越小，方框线条越细

【边缘反弹】
代码：
  float bounceDamping = 0.3;
  float boxPadding = 4;
说明：
  - bounceDamping 控制字符撞到方框边缘后的反弹力度
  - 数值越接近 1，反弹越明显
  - 数值越小，反弹越柔和
  - boxPadding 控制字符离边框保留的内边距

----------------------------------------
文字内容与初始排布
----------------------------------------

【每行文字内容】
代码：
  String[] rowTexts = { ... };
说明：
  - 每一行会从 rowTexts 中取一句英文
  - 如果 rowCount 超过 rowTexts 的数量，会循环使用
  - 可以直接替换成自己的英文短句

【左侧文字位置】
代码：
  float pileX = 78;
说明：
  - 控制文字堆叠起点的 x 坐标
  - 数字越小，文字越靠左
  - 数字越大，文字越靠右

【显示行数】
代码：
  int rowCount = 12;
说明：
  - 控制画面中显示多少行文字
  - 数字越大，行数越多

【第一行位置】
代码：
  float firstRowY = 450;
说明：
  - 控制第一行文字的 y 坐标
  - 数字越大，整体文字越靠下
  - 数字越小，整体文字越靠上

【随机行距范围】
代码：
  float minRowGap = 18;
  float maxRowGap = 30;
说明：
  - 每行之间会随机取一个距离
  - minRowGap 是最小行距
  - maxRowGap 是最大行距
  - 范围越大，行距越参差

【左侧压缩字距】
代码：
  float minCompactSpacing = 0.45;
  float maxCompactSpacing = 0.9;
说明：
  - 控制每行最开始字符之间的距离
  - 数值越小，左侧越密集
  - 数值越大，文字展开得越长

【字距增长】
代码：
  float minSpacingGrowth = 0.10;
  float maxSpacingGrowth = 0.24;
  float spacingCurve = 0.1;
说明：
  - 控制越往右字距越疏的层级感
  - minSpacingGrowth 和 maxSpacingGrowth 越大，右侧越散
  - spacingCurve 控制疏密变化曲线

【横向细微错位】
代码：
  float rowLooseJitter = 0.8;
说明：
  - 给每个字符一点横向随机错位
  - 数字越大，行内越不整齐
  - 数字越小，行内更规整

【字符大小】
代码：
  float minTextSize = 9;
  float maxTextSize = 25;
说明：
  - 控制字符字号随机范围
  - 数值越大，字符越大
  - 如果程序卡顿，可以适当降低 maxTextSize

----------------------------------------
行触发与散开
----------------------------------------

【鼠标触发范围】
代码：
  float touchYRange = 9;
说明：
  - 鼠标离某一行多近时触发这一整行
  - 数字越大，越容易触发
  - 数字越小，需要更精确地靠近那一行

【从右到左散开的速度】
代码：
  int evaporationGap = 3;
说明：
  - 控制一行中相邻字符开始散开的间隔帧数
  - 数字越大，从右到左散开越慢
  - 数字越小，整行散开越快

【初始向右上方漂浮速度】
代码：
  float minRiseSpeed = 1.2;
  float maxRiseSpeed = 3.0;
  float minRightSpeed = 0.4;
  float maxRightSpeed = 2.0;
说明：
  - RiseSpeed 控制向上速度
  - RightSpeed 控制向右速度
  - 范围越大，不同字符速度差异越明显

【整体右上力度】
代码：
  float rightPush = 1.4;
  float upwardPush = 1.25;
说明：
  - rightPush 越大，字符越往右飘
  - upwardPush 越大，字符越往上飘

【漂浮透明度】
代码：
  float floatingAlpha = 255;
说明：
  - 255 是完全不透明
  - 数字越小，漂浮字符越透明
  - 当前字符不会自动消失

【泡泡晃动】
代码：
  float bubbleWobble = 5;
  float floatingDrift = 0.04;
说明：
  - bubbleWobble 控制漂浮时的横向晃动
  - floatingDrift 控制持续细微流动
  - 如果觉得画面卡顿，可以适当降低 bubbleWobble

----------------------------------------
鼠标搅动
----------------------------------------

【搅动范围和力度】
代码：
  float stirRadius = 95;
  float stirPush = 0.18;
  float stirSwirl = 0.14;
  float stirMaxSpeed = 3.2;
说明：
  - stirRadius 控制鼠标影响范围
  - stirPush 控制向外推开的力度
  - stirSwirl 控制旋涡搅动感
  - stirMaxSpeed 控制被搅动后的最大速度

【搅动后的阻尼】
代码：
  float velocityDamping = 0.992;
  float rotationDamping = 0.94;
  float maxRotSpeed = 0.08;
说明：
  - velocityDamping 控制移动速度衰减
  - rotationDamping 控制旋转速度衰减
  - maxRotSpeed 限制最高转速
  - 如果字符转太久，可以把 rotationDamping 调小
  - 如果字符整体运动太久，可以把 velocityDamping 调小

----------------------------------------
性能优化
----------------------------------------

当前程序已经做了这些优化：
  - 背景图片只在 setup() 中缩放一次
  - 未触发的文字会缓存到 staticTextLayer
  - 每个字符会预先渲染成 glyphImage
  - 每帧只更新已经漂浮的字符

如果仍然卡顿，可以尝试：
  - 降低 rowCount
  - 降低 maxTextSize
  - 降低 bubbleWobble
  - 降低 stirRadius
  - 临时隐藏方框：showBox = false
  - 使用尺寸更接近 600 x 800 的背景图片


========================================
6. 常见问题
========================================

Q1：为什么背景图片没有显示？
  - 检查图片是否放在 dense_stacked_characters_600x800 文件夹中
  - 检查文件名是否和 backgroundFile 一致
  - 当前代码默认使用 backgroud.jpg

Q2：为什么看不到方框？
  - 当前 showBox 默认为 false
  - 如果想调试方框范围，把 showBox 改成 true
  - 方框隐藏时，反弹范围依然存在

Q3：为什么鼠标碰到文字后整行都散开？
  - 这是当前交互设定
  - 鼠标进入某一行的 y 范围后，会触发整行
  - 如果想更难触发，可以调小 touchYRange

Q4：为什么字符不会消失？
  - 当前设定是字符一直在方框里漂浮
  - floatingAlpha 控制透明度，但不会自动淡出

Q5：为什么字符转动越来越快？
  - 当前版本已经加入 rotationDamping 和 maxRotSpeed
  - 如果仍然觉得转得太快，可以降低 stirSwirl 或 maxRotSpeed
  - 也可以把 rotationDamping 调小，例如 0.88

Q6：为什么画面卡顿？
  - 漂浮字符数量太多或鼠标搅动范围太大都可能影响性能
  - 可以降低 rowCount、maxTextSize、bubbleWobble 或 stirRadius
  - 也可以换成更小尺寸的背景图片

Q7：如何重置画面？
  - 按 R 键
  - 所有字符会重新生成
  - 已触发行会恢复到未触发状态

结束
========================================

建议调参顺序：
  1. 先调 boxX、boxY、boxW、boxH，确定漂浮范围
  2. 再调 rowCount、firstRowY、minRowGap、maxRowGap，确定文字排布
  3. 再调 rightPush、upwardPush、bounceDamping，确定漂浮感觉
  4. 最后调 stirRadius、stirPush、stirSwirl，确定鼠标搅动强度
