========================================
1. 基本信息
========================================

程序名称：drag_line_600x800 鼠标轨迹落字
开发环境：Processing 3.x 或 4.x
画布尺寸：600 x 800 像素

主要特点：
  - 鼠标按住拖动时，会在画面上留下黑色轨迹线
  - 字母会沿着鼠标轨迹附近生成
  - 字母不会均匀排列，而是有疏密变化
  - 字母大小、距离线条的位置、角度都有轻微随机感
  - 按 m 键可以开启或关闭字母浮动
  - 在静态状态下，如果字母之间靠得太近，会触发掉落
  - 掉落的字母会受到重力影响，落地后回弹，并逐渐停住
  - 按 r 键可以清空画面并重置浮动开关


========================================
2. 安装与运行
========================================

步骤1：安装 Processing
  - 访问 https://processing.org/download
  - 下载并安装适合你电脑系统的版本

步骤2：打开项目文件夹
  - 找到项目文件夹：drag_line_600x800
  - 打开 drag_line_600x800.pde

步骤3：确认资源文件
  - 字体文件 Luminari.ttf 需要放在 data 文件夹里
  - 当前路径应为：drag_line_600x800/data/Luminari.ttf
  - 当前程序不需要安装额外库
  - 当前程序不使用声音、麦克风或摄像头

步骤4：运行程序
  - 点击 Processing 左上角的运行按钮
  - 或按快捷键：
    Windows/Linux：Ctrl + R
    Mac：Cmd + R

注意：
  - 如果字体没有显示，优先检查 data/Luminari.ttf 是否存在
  - 如果修改了字体文件名，需要同步修改代码里的 letterFontName
  - Processing 项目文件夹名称需要和主 pde 文件名称一致


========================================
3. 交互方式
========================================

鼠标拖动画线：
  - 按住鼠标并拖动
  - 鼠标经过的位置会留下黑色线条轨迹
  - 线条会保留在画面上，不会自动消失

轨迹生成字母：
  - 拖动画线时，字母会在轨迹附近生成
  - 字母会沿着鼠标运动方向旋转
  - 字母不会完全贴在线条中心，而是会随机偏离线条一点
  - 字母生成有疏密变化，有些地方密，有些地方稀

m 键：字母浮动开关
  - 按 m 键开启字母浮动
  - 再按一次 m 键关闭字母浮动
  - 浮动开启时，每个字母会以不同幅度和速度轻微移动
  - 有一小部分字母不会浮动，保持静止

静态碰撞掉落：
  - 当 m 键浮动关闭时，程序处于静态状态
  - 静态状态下，如果不同位置的字母靠得太近，会触发碰撞
  - 被碰撞的字母会从原位置掉落
  - 掉落后会在设定的地面位置回弹
  - 回弹速度变小时，字母会停住，不再继续抖动

r 键：重置画面
  - 按 r 键清空所有线条和字母
  - 字母内容顺序会重新从头开始
  - m 键的浮动开关也会重置为关闭


========================================
4. 画面结构说明
========================================

画面由这些部分组成：
  - 浅灰色背景 #f3f3f5
  - 鼠标拖动生成的黑色线条
  - 沿轨迹附近生成的黑色字母
  - 碰撞后掉落并回弹的字母

图层顺序：
  1. 背景色
  2. 轨迹线图层 lineLayer
  3. 字母对象 trailLetters

说明：
  - 线条画在单独的 PGraphics 图层 lineLayer 上
  - 字母是 TrailLetter 对象
  - 每个字母都有自己的位置、角度、大小、浮动速度和浮动幅度
  - 每次鼠标按下会开始一条新的 strokeIndex
  - 程序会避免同一条轨迹上太近的相邻字母立刻互相触发掉落
  - 掉落字母不会互相堆叠支撑，因此可以重叠在同一区域


========================================
5. 参数调整指南
========================================

提示：
  - 使用 Ctrl + F 或 Cmd + F 搜索参数名称
  - 修改数值后重新运行程序查看效果
  - 建议每次只改一两个参数，方便判断变化

----------------------------------------
画布和背景
----------------------------------------

【画布尺寸】
位置：settings()
代码：size(600, 800);
说明：
  - 600 是画布宽度
  - 800 是画布高度

【背景颜色】
位置：setup() 和 draw()
代码：background(#f3f3f5);
说明：
  - 当前背景是浅灰色 #f3f3f5
  - 如果想换背景颜色，需要同时修改 lineLayer.background() 和 draw() 里的 background()

----------------------------------------
线条参数
----------------------------------------

【线条粗细】
代码：float lineThickness = 1.5;
说明：
  - 数字越大，线条越粗
  - 数字越小，线条越细

【线条圆滑度】
代码：int lineSmooth = 20;
说明：
  - 数字越大，线条边缘越圆滑
  - 如果运行变慢，可以适当减小

----------------------------------------
字体和文字内容
----------------------------------------

【字母内容】
代码：String letters = "Sometimes the wind writes in silence";
说明：
  - 控制轨迹旁循环生成的文字内容
  - 可以替换成英文句子或单词
  - 程序会自动跳过空格，只显示字符

【字体文件】
代码：String letterFontName = "Luminari.ttf";
说明：
  - 字体文件需要放在 data 文件夹中
  - 文件名必须和 letterFontName 完全一致
  - 如果换字体，只需要替换 data 里的字体文件，并修改这里的文件名

【字母随机大小】
代码：
  float letterMinSize = 10;
  float letterMaxSize = 20;
说明：
  - 每个字母会在最小字号和最大字号之间随机取值
  - letterMinSize 控制最小字号
  - letterMaxSize 控制最大字号

----------------------------------------
字母生成密度
----------------------------------------

【字母整体密度】
代码：float letterGap = 16;
说明：
  - 控制字母之间的整体距离
  - 数字越小，字母越密
  - 数字越大，字母越疏

【字母疏密变化】
代码：float letterGapVariation = 20;
说明：
  - 控制字母间距的随机变化
  - 数字越大，疏密差异越明显
  - 数字越小，排列越接近均匀

【密集段概率】
代码：float denseChance = 0.45;
说明：
  - 控制密集段出现的概率
  - 范围建议保持在 0 到 1 之间
  - 数字越大，密集段越多

----------------------------------------
字母位置和角度
----------------------------------------

【字母离轨迹距离】
代码：
  float letterMinOffset = 10;
  float letterMaxOffset = 22;
说明：
  - 字母不会压在线条中心，而是在轨迹两侧随机偏移
  - letterMinOffset 控制最小偏移距离
  - letterMaxOffset 控制最大偏移距离
  - 如果字母离线太远，可以减小 letterMaxOffset

【字母角度随机感】
代码：float letterAngleJitter = 0.18;
说明：
  - 控制字母角度相对轨迹方向的随机变化
  - 0 表示完全跟随轨迹方向
  - 数字越大，字母角度越散

----------------------------------------
字母浮动
----------------------------------------

【浮动开关】
代码：boolean letterFloatEnabled = false;
说明：
  - false 表示默认不浮动
  - true 表示默认浮动
  - 运行时按 m 键可以切换

【浮动幅度范围】
代码：
  float letterMinFloatAmount = 0;
  float letterMaxFloatAmount = 10;
说明：
  - 每个字母的浮动幅度会在这个范围里随机
  - 数字越大，晃动越明显
  - 如果想更安静，可以减小 letterMaxFloatAmount

【浮动速度范围】
代码：
  float letterMinFloatSpeed = 0.01;
  float letterMaxFloatSpeed = 0.1;
说明：
  - 每个字母的浮动速度会在这个范围里随机
  - 数字越大，动得越快
  - 如果想更慢，可以减小 letterMaxFloatSpeed

【不浮动概率】
代码：float letterStillChance = 0.05;
说明：
  - 控制有多少字母完全不浮动
  - 0 表示所有字母都可以浮动
  - 1 表示所有字母都不浮动

----------------------------------------
碰撞和掉落
----------------------------------------

【碰撞掉落开关】
代码：boolean letterCollisionEnabled = true;
说明：
  - true 表示开启静态碰撞掉落
  - false 表示关闭碰撞掉落
  - 碰撞掉落只在 m 键浮动关闭时检测

【碰撞范围】
代码：float letterCollisionScale = 0.55;
说明：
  - 控制字母多近时算作碰撞
  - 数字越大，越容易触发掉落
  - 数字越小，需要更靠近才会掉落

【重力】
代码：float letterGravity = 0.18;
说明：
  - 控制字母掉落速度增长
  - 数字越大，掉得越快
  - 数字越小，掉得越慢

【落地位置】
代码：float letterFloorY = 730;
说明：
  - 控制字母掉到哪里开始回弹
  - 数字越大，落点越靠下
  - 数字越小，落点越靠上

【回弹力度】
代码：float letterBounce = 0.32;
说明：
  - 控制字母落地后的弹起高度
  - 数字越大，弹得越高
  - 数字越小，弹得越轻

【地面摩擦】
代码：float letterFloorFriction = 0.26;
说明：
  - 控制字母落地后横向速度衰减
  - 数字越小，越快停下横向滑动
  - 数字越大，横向滑动保留越多

【停止阈值】
代码：float letterSettleSpeed = 0.7;
说明：
  - 控制字母什么时候停止弹动
  - 数字越大，越快停住
  - 数字越小，会多弹几下再停

----------------------------------------
快捷键
----------------------------------------

【m 键】
说明：
  - 开启或关闭字母浮动
  - 浮动开启时，碰撞掉落不会继续触发

【r 键】
说明：
  - 清空线条和所有字母
  - 重置文字生成顺序
  - 重置 m 键浮动开关为关闭


========================================
6. 常见问题
========================================

问题1：字体没有显示或变成默认字体
  - 确认 data/Luminari.ttf 存在
  - 确认代码里的 letterFontName 和字体文件名完全一致
  - 如果换了字体文件名，需要同步修改 letterFontName

问题2：鼠标拖动没有生成线条
  - 确认是按住鼠标拖动，而不是只移动鼠标
  - 确认程序正在运行窗口中
  - 如果按 r 后清空画面，需要重新拖动生成

问题3：字母太密或太稀
  - 修改 letterGap 控制整体密度
  - 修改 letterGapVariation 控制疏密变化
  - 修改 denseChance 控制密集段出现概率

问题4：字母离线太近，遮挡线条
  - 增大 letterMinOffset
  - 或增大 letterMaxOffset

问题5：字母离线太远
  - 减小 letterMaxOffset
  - 也可以减小 letterMinOffset

问题6：字母浮动太强
  - 减小 letterMaxFloatAmount
  - 减小 letterMaxFloatSpeed
  - 或按 m 键关闭浮动

问题7：字母浮动太弱
  - 增大 letterMaxFloatAmount
  - 增大 letterMaxFloatSpeed
  - 减小 letterStillChance

问题8：字母太容易掉落
  - 减小 letterCollisionScale
  - 或关闭 letterCollisionEnabled

问题9：字母不容易掉落
  - 增大 letterCollisionScale
  - 让轨迹之间更接近或交叉
  - 确认当前没有开启 m 键浮动

问题10：字母落地后还动很久
  - 增大 letterSettleSpeed
  - 减小 letterBounce
  - 减小 letterFloorFriction

问题11：按 r 后浮动还是开启
  - 当前版本按 r 会自动把 letterFloatEnabled 重置为 false
  - 如果仍然浮动，确认代码里的 resetSketch() 中有 letterFloatEnabled = false;

问题12：运行有卡顿
  - 减小 lineSmooth
  - 减少字母数量，例如增大 letterGap
  - 减小 letterGapVariation 和 denseChance，减少密集段
  - 如果画面上字母很多，可以按 r 清空重来
